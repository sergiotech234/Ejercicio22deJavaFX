# Selector de Opciones en Java (Diálogo)

## Descripción

Este proyecto consiste en una aplicación desarrollada en **Java** que permite mostrar un **cuadro de diálogo con varias opciones** al pulsar un botón. Una vez que el usuario selecciona una opción, esta se muestra por consola.

El objetivo principal del ejercicio es practicar el uso de interfaces gráficas en Java y la interacción con eventos de usuario mediante botones y cuadros de diálogo.

## Objetivos

- Crear una interfaz gráfica sencilla en Java.
- Implementar un botón con gestión de eventos.
- Mostrar un diálogo de selección de opciones.
- Capturar la opción elegida por el usuario.
- Mostrar el resultado en la consola.

## Funcionamiento

1. Se inicia la aplicación.
2. Se muestra una ventana con un botón.
3. Al pulsar el botón aparece un cuadro de diálogo con distintas opciones.
4. El usuario selecciona una opción.
5. La opción seleccionada se imprime en la consola.

## Ejemplo de uso

Al pulsar el botón aparecerá un diálogo similar a:

```text
Seleccione una opción:

[Opción 1]
[Opción 2]
[Opción 3]
```

Si el usuario selecciona:

```text
Opción 2
```

La consola mostrará:

```text
Opción seleccionada: Opción 2
```
